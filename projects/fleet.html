How it works

Fleet v1.12.0 runs directly inside Antigravity's auxiliary pane (SIDECAR_UI_ENTRYPOINT_AUX_PANE, installed atomically to ~/.gemini/config/plugins/fleet/) backed by a zero-dependency Node ESM sidecar (293.8 KiB raw / 91.66 KiB (93,861 B) pre-gzipped -47.2% raw vs baseline, 143.43 ms --jitless cold boot -1.8%, 69.16 MB --jitless peak RSS -2.0% / -67.4% vs baseline, 1,038.9 req/s / 1,032.3 req/s --jitless). The legacy standalone Rust server remains preserved at tag v0.12.0.

01 · Gate Readiness & Token Burn Guard

Track gates & burn loops at a glance

computeGateReadiness tracks [done] → [verified] → [blocked] with 1-click Gate #seq jumps while computeBurnSummary spots high-burn workers (High burn · @worker %).

02 · 69.16 MB --jitless RSS & 91.66 KiB Gzip

Zero-alloc Buffer span transcript scans

Eliminating 2k+ per-line Buffer.subarray() wrappers alongside bounded V8 heap (--max-old-space-size=24) & semantic CSS cuts --jitless Peak RSS -67.4% to 69.16 MB.

03 · Broadcast, Export & 30/30 Cold Fuzz

CWE-22/59 confinement & clean exports

Validated multi-target POST /api/nudge, ~/-masked Filtered Board Export, confined /api/worktrees/diff, and 30/30 raw-TCP fuzz security checks pass.
