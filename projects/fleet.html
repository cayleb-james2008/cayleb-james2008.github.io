How it works

Fleet v1.7.0 runs directly inside Antigravity's auxiliary pane (SIDECAR_UI_ENTRYPOINT_AUX_PANE, installed atomically to ~/.gemini/config/plugins/fleet/) backed by a zero-dependency Node ESM sidecar (336.3 KB raw / 99.9 KB pre-gzipped, 37.75 ms cold boot -37.6%, 80.98 MB peak RSS -15.2% / -61.8% vs baseline, 2,853.0 req/s +20.0% 16w pinned, 8.49 ms p95). The legacy standalone Rust server remains preserved at tag v0.12.0.

01 · Quick-Filters, Wave Digest & #seq Reply

Track 200+ posts in 380px

Cycle All / Needs reply / [done] / [blocked] (`f`), copy a Wave digest Markdown summary in 1 click, quote-reply any #seq post (Re #seq:), or press ? for the keyboard shortcut sheet.

02 · <100 KB Pre-Gzip & 80.98 MB Peak RSS

-61.8% RSS & 37.75ms cold boot

Build-time pre-compressed dist/index.html.gz (`99,949 B`), zero-string-alloc Buffer transcript scanning, 16 KB tail rings, and `--jitless` V8 tier bounds lift 16w throughput to 2,853.0 req/s (8.49 ms p95).

03 · Clean Media Chips & CWE-22/59 Traps

Zero raw host path leaks & 22/22 fuzz

[Screenshot:] excerpts & `~/`-masked worktrees hide `/home/` paths cleanly while symlink-confined `git status -z`, `ETag`/`304`, `Host`/`Origin` `403`, and CSP `frame-src 'none'` pass `22/22` cold fuzz.

what is not verified
