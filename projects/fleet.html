Flagship v0.10.0 · Single-Binary Rust Desktop & Web App · checked 25 November 2026

Hand out the work. It comes back verified.

Fleet is a Codex/Linear parallel coding-agent workbench served from a single cross-platform Rust binary (8.27 MB, -24.8% vs v0.9.0; Linux, macOS, and native Windows .exe with chromeless desktop app launch). Each task runs non-interactively in its own git worktree (opencode, Claude Code, Codex) with gzip + ETag/304 static serving (421.2 KB wire, 6,255.9 req/s, 9.00 ms p95), a Goal-to-DAG planner, 1-click Batch Merge with git merge-tree conflict preflight, enriched Auto-Heal (modified files, diff hunks, prior failures), instant keyboard triage (y/x/m/s/[/]/1–4), live duration & budget headroom, PR Preview & confirmation-gated GitHub PR creator, and Worktrees Inspector.

How it works

Fleet v0.10.0 coordinates parallel coding-agent runs locally across Linux, macOS, and Windows in an 8.27 MB Rust binary with gzip/ETag static serving (421.2 KB wire, 6,255.9 req/s, 9.00 ms p95), Goal-to-DAG orchestration, 1-click Batch Merge with git merge-tree conflict preflight, enriched Auto-Heal steering, instant keyboard triage, and strict committed-tree verification.

01 · Goal-to-DAG & Enriched Auto-Heal

Multi-wave delivery with hard fences

Decompose goals into wave-gated tasks across Board and DAG Graph views while enriched Auto-Heal injects modified worktree files, bounded diff excerpts, and prior failed attempt context under a SHA-256 loop breaker.

02 · Batch Merge & Keyboard Triage

One-click verified wave shipping

Run POST /api/sessions/batch-merge with non-destructive git merge-tree conflict preflight from the toolbar, DAG Graph, or Cmd+K, triage Needs you via y/x/m/s/[/], and gate GitHub PRs behind explicit preview + confirmation.

03 · Worktrees, Headroom & Security

Safe resource governance

Inspect live session duration, timeout/heal/daily budget headroom, prune non-main orphan worktrees with CWE-59 symlink checks, block traversal/invalid session IDs, and return prompt 413 on open client write halves.

what is not verified

  • Local operator boundary: Fleet runs locally on the operator’s machine (Unix process groups + Windows job-object containment) and executes the check commands configured by the operator.
  • Signed-in CLI credentials: running real third-party coding agents or publishing GitHub PRs requires local authentication for those CLIs on the host; PR creation always stops at explicit preview + confirmation.
