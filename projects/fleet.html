Hand out the work. It comes back verified.

Fleet is a Codex/Linear parallel coding-agent workbench served from a single cross-platform Rust binary (Linux, macOS, and native Windows .exe with chromeless desktop app launch, -24.1% bundle). Each task runs non-interactively in its own git worktree (opencode, Claude Code, Codex) with a Goal-to-DAG planner, interactive multi-wave Board / DAG Graph toggle, PR Preview & confirmation-gated GitHub PR creator, Worktrees Inspector with safe non-main orphan pruning, Daily Dispatch Budget guardrails (429 on cap), autonomous Auto-Heal feedback steering, reusable Playbooks, live Board Telemetry, and committed-tree verification.

How it works

Fleet v0.9.0 coordinates parallel coding-agent runs locally across Linux, macOS, and Windows against your own git repositories, combining a Goal-to-DAG planner, interactive multi-wave DAG orchestration, confirmation-gated GitHub PR previews, safe worktree lifecycle management, daily dispatch caps, autonomous Auto-Heal steering, and strict committed-tree verification.

01 · Goal-to-DAG & Auto-Heal

Multi-wave delivery with hard fences

Decompose goals into wave-gated tasks and switch between Board and interactive DAG Graph views to inspect depends_on waves, while healable check failures automatically steer via --continue with a SHA-256 identical-error loop breaker — never bypassing file-scope or commit refusals.

02 · PR Preview & Playbooks

One-click verified shipping

Generate structured PR titles, bodies, and diff summaries from verified receipts before confirmation-gated gh pr create execution, dry-run merges against dirty targets, or launch reusable engineering Playbooks via Cmd+K.

03 · Worktrees, Budget & Windows

Safe resource governance

Inspect every git worktree across repos and safely prune stale non-main orphans (never touching active sessions or main), enforce configurable Daily Dispatch Budget caps (429 on overrun), and run natively on Linux, macOS, and Windows.

what is not verified

  • Local operator boundary: Fleet runs locally on the operator’s machine (Unix process groups + Windows job-object containment) and executes the check commands configured by the operator.
  • Signed-in CLI credentials: running real third-party coding agents or publishing GitHub PRs requires local authentication for those CLIs on the host; PR creation always stops at explicit preview + confirmation.
