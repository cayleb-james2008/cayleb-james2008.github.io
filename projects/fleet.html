Release v1.19.0 · Antigravity Swarm Sidebar Plugin · checked 25 November 2026

Track the whole swarm from the side pane.

Fleet v1.19.0 runs inside Antigravity's auxiliary side pane (SIDECAR_UI_ENTRYPOINT_AUX_PANE, installed into ~/.gemini/config/plugins/fleet/ via ./install.sh) backed by a zero-dependency Node ESM sidecar. How it works

Fleet watches Antigravity's swarm board and transcript files over read-only local streams and packages the entire UI as a single pre-gzipped asset inside ~/.gemini/config/plugins/fleet/.

01 · Idle Sleep & Full Swarm Archive

Sleep when idle and export full sanitized archives

The sidecar boots idle with zero background polling, pauses sseTimer on last disconnect, wakes on request, and exports masked fleet.swarm-archive.v1 JSON or Markdown alongside live activity peeks.

02 · 88.59 ms --jitless & 2,110.8 req/s

Faster cold boot and +30.5% HTTP throughput

Deferring heavy warmup until client arrival trims --jitless cold boot by -23.4% to 88.59 ms, holds --jitless RSS at 68.02 MB, and lifts HTTP +30.5% to 2,110.8 req/s (9.87 ms p95).

03 · Confinement & Export

Guarded diffs and masked logs

Multi-target POST /api/nudge bounds, path-confined /api/worktrees/diff checks, and ~/ home masking on board exports pass 30 raw-TCP security tests.

Known limits

  • Fleet reads Antigravity <appData>/brain/ swarm state read-only and never calls model APIs itself. Worker nudges stop for confirmation and route through Antigravity's bridge.
  • toggleConversation, toggleAuxPane, and agent.sendMessage host hooks require Antigravity (SidecarApp / /preload.js); standalone mode and /demos/fleet/ run the offline simulator.
