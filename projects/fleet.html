How it works

Fleet v1.1.0 runs directly inside Antigravity's auxiliary pane (SIDECAR_UI_ENTRYPOINT_AUX_PANE, installed atomically to ~/.gemini/config/plugins/fleet/) backed by a zero-dependency Node ESM sidecar (470.5 KB raw / 142.7 KB gzip, 72.25 ms cold boot, 129.01 MB peak RSS, 1,496.8 req/s, 30.39 ms p95). The legacy standalone Rust server remains preserved at tag v0.12.0.

01 · Zero-Clipping Tabs & Activity Peek

Built for 340px–380px sidebars

All 5 tabs (Triage, Board, Roster, Graph, Git) fit cleanly with sentence-case headings and flat hairlines (0 FAIL / 0 WARN sloplint), while expandable Activity Peek drawers reveal each worker's latest thinking heading, last 5 tool calls, and token breakdown before opening chat.

02 · Swarm Digest & Incremental JSONL Tailing

Instant status & lean memory

1-click Copy swarm digest emits a Markdown status snapshot from the header or Cmd/Ctrl+K palette, while swarm_store.mjs tails board.jsonl and transcript.jsonl in 128 KB byte-offset chunks with automatic inode/truncation reset.

03 · Cached Worktrees & Loopback Hardening

Strict CWE-22/59 & Origin isolation

Debounced git worktree status probes and /api/frame screenshot reads enforce CWE-22/CWE-59 symlink/root confinement alongside strong SHA-256 ETag/304, Host/Origin 403 guards, 413 payload limits, and CSP frame-src 'none'.

what is not verified
