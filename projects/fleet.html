How it works

Fleet v1.10.0 runs directly inside Antigravity's auxiliary pane (SIDECAR_UI_ENTRYPOINT_AUX_PANE, installed atomically to ~/.gemini/config/plugins/fleet/) backed by a zero-dependency Node ESM sidecar (292.5 KiB raw / 91.1 KiB (93,290 B) pre-gzipped -3.8% raw / -0.9% gz, 112.13 ms --jitless cold boot -18.0%, 72.46 MB --jitless peak RSS -65.8% vs baseline, 1,721.3 req/s +17.8% with 12.93 ms p95 -18.1%). The legacy standalone Rust server remains preserved at tag v0.12.0.

01 · Broadcast Composer & Filtered Board Export

Coordinate waves & export clean logs

Confirmation-gated Broadcast Composer sends validated multi-target POST /api/nudge messages (conversationIds, 1..24) while Filtered Board Export downloads .md/.json with ~/-masked paths.

02 · 91.1 KiB Gzip & +17.8% Cold Throughput

Pre-serialized payloads & -18.0% boot

Eliminating per-request gunzipSync on /api/swarm plus lazy git_probe/font loading lifts 16w HTTP to 1,721.3 req/s (12.93 ms p95 -18.1%) and trims --jitless boot to 112.13 ms.

03 · Heat Bar, Diff Peek & 30/30 Cold Fuzz

CWE-22/59 confinement & cog UI

Bounded GET /api/worktrees/diff via realpathSync, Swarm Bottleneck Heat Bar + Copy Blocker, cog Settings & Wrench SVGs, and 30/30 raw-TCP fuzz security checks pass.

what is not verified

  • Read-only transcript & worktree boundary: Fleet reads Antigravity <appData>/brain/ swarm state read-only and never invokes model APIs directly; nudge dispatch always stops at confirmation and routes through Antigravity's native bridge.
  • Host Antigravity requirement: toggleConversation, toggleAuxPane, and agent.sendMessage host controls activate when loaded inside Antigravity (SidecarApp / /preload.js); standalone preview and /demos/fleet/ show the offline simulator.
