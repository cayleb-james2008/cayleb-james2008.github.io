Flagship v0.11.0 · Single-Binary Rust Desktop & Web App · checked 25 November 2026

Hand out the work. It comes back verified.

Fleet is a Codex/Linear parallel coding-agent workbench served from a single cross-platform Rust binary (8.44 MB; Linux, macOS, and native Windows .exe with chromeless desktop app launch). Each task runs non-interactively in its own git worktree (opencode, Claude Code, Codex) with 15.42 ms cold boot (-90.0%, 10x faster via in-process $PATH scan, single-pass PersistedStore, and background hydration), gzip + ETag/304 static serving (7,048.0 req/s, 5.73 ms p95), Wave Preflight & confirmation-gated Batch PR (WaveShipModal + POST /api/sessions/batch-pr), and an Auto-Heal Failure Classifier (CompileError, TestAssertion, LintOrFormat, ScopeGuardrail, Timeout, TransientFlake).

How it works

Fleet v0.11.0 coordinates parallel coding-agent runs locally across Linux, macOS, and Windows in an 8.44 MB Rust binary with 15.42 ms cold boot (10.0x faster than v0.10.0), gzip/ETag static serving (7,048.0 req/s, 5.73 ms p95), Wave Preflight & confirmation-gated Batch PR, Auto-Heal Failure Classification, and strict committed-tree verification.

01 · 10x Faster Boot & Auto-Heal Classifier

Zero-lag startup & targeted repair

In-process $PATH agent discovery and background hydration boot in 15.42 ms even with 2,000 sessions, while classify_failure categorizes check failures (CompileError, TestAssertion, LintOrFormat, ScopeGuardrail, Timeout, TransientFlake) for tailored Auto-Heal prompts.

02 · Wave Preflight & Batch PR

One-click verified wave shipping

WaveShipModal previews non-destructive git merge-tree clean vs conflicting files per session with strategy selection (merge / squash / ff), 1-click Merge clean, and confirmation-gated POST /api/sessions/batch-pr.

03 · Worktrees, Triage & Security

Safe resource governance

Instant keyboard triage (y/x/m/s/[/]/1–4), CWE-59 symlink checks before worktree removal, strict session ID & ../NUL repo guards, prompt 413 on open client write halves, and Host-403 isolation.

what is not verified

  • Local operator boundary: Fleet runs locally on the operator’s machine (Unix process groups + Windows job-object containment) and executes the check commands configured by the operator.
