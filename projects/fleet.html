How it works

Fleet v1.4.0 runs directly inside Antigravity's auxiliary pane (SIDECAR_UI_ENTRYPOINT_AUX_PANE, installed atomically to ~/.gemini/config/plugins/fleet/) backed by a zero-dependency Node ESM sidecar (406.4 KB raw / 120.0 KB gzip -17.5% gz, 84.73 ms pinned boot, 109.54 MB peak RSS -10.8%, 1,324.0 req/s 16w pinned, 17.17 ms p95 -33.4%). The legacy standalone Rust server remains preserved at tag v0.12.0.

01 · Keyboard Triage & Pin #seq

j/k/o/p/1-5 without leaving keyboard

Move focus across Needs-You items (j/k), open worker chat (o/Enter), pin critical posts to the top of Board & Triage (p), jump tabs (1–5), and stream live updates over bounded /api/swarm/stream SSE.

02 · Worktree Changed-File Links & Aux Pane

1-click Open file inside worktree root

git_probe.mjs parses git status --porcelain=v1 -z with strict symlink/root confinement inside each worktree, wiring per-file Open file rows (toggleAuxPane fileView) alongside 1-click Unstick presets and Context Pressure bars.

03 · Zero-Dep Motion & 109 MB RSS Diet

406 KB bundle & -33.4% p95 latency

Removing @radix-ui/react-dialog & motion/react in favor of native GPU Element.animate trims the bundle by 17.5% gzip while bounded LRU caches & 32-slot rings keep Peak RSS at 109.54 MB (22/22 cold fuzz, 5/5 SSE).
