How it works

Fleet v1.8.0 runs directly inside Antigravity's auxiliary pane (SIDECAR_UI_ENTRYPOINT_AUX_PANE, installed atomically to ~/.gemini/config/plugins/fleet/) backed by a zero-dependency Node ESM sidecar (315.4 KiB raw / 93.1 KiB (`95,371 B`) pre-gzipped, 82.35 ms cold boot, 72.72 MB `--jitless` peak RSS / 80.55 MB zero-flag -65.7% vs baseline, 1,385.7 req/s with 24.65 ms max tail -93.8%). The legacy standalone Rust server remains preserved at tag v0.12.0.

01 · Inline Worktree Diff Peek & CWE-22/59

Bounded hunks without leaving 380px

Expandable Diff peek toggles (GET /api/worktrees/diff) stream bounded <= 8 KB git diff HEAD hunks and untracked previews strictly confined via realpathSync against traversal and symlink escapes.

02 · 93.1 KiB Gzip & 72.72 MB --jitless RSS

-93.8% max latency & native crc32 ETag

Shared SVG primitives trim pre-gzipped UI to 93.1 KiB, native zlib.crc32 removes node:crypto OpenSSL RSS, and bounded buf.subarray transcript scans fix quadratic 50k-line stalls (24.65 ms max).

03 · Quick-Filters, Wave Digest & 28/28 Fuzz

Zero raw host path leaks & full confinement

Board quick-filter pills (f), 1-click Wave digest, #seq Quote-Reply, ~/-masked paths, and +6 /api/worktrees/diff traversal/rebind checks pass 28/28 cold fuzz.

what is not verified
